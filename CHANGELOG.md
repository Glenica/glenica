# Changelog

All notable changes to the Glenica extension are listed here.

## 0.1.2 (2026-10-10)

- New name: **Glenica for n8n**, in the browser and in the sidebar header.

## 0.1.1 (2026-10-10): Early access

The first public build of Glenica, available here while the Chrome Web Store listing is in review.

- Build n8n workflows from a plain-English description: Glenica shows a plan, then places the nodes on your canvas in labelled sections.
- Fix failed runs: Glenica reads the error, shows the exact change before applying it, and runs the workflow again.
- Ask about any node or expression in your workflow.
- Undo any change, node by node or all at once.
- Works with n8n Cloud, self-hosted n8n and localhost.
- Use your Claude Pro or Max plan, or OpenRouter.
